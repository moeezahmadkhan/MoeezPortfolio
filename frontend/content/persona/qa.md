honest answers beat any amount of prompt engineering. Nobody else fills these in:
an unanswered heading is dropped by `tools/build_persona_index.mjs`, so a partly
filled file is fine and a fabricated one is a defect. Answer as many as you want,
in any order, then run `npm run persona`.
